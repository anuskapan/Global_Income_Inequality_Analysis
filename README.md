# 🌍 Global Income Inequality Analysis

A data-driven web application built using Python and Streamlit to analyze and visualize global income inequality trends using publicly available datasets across the world.

This platform enables interactive exploration of income distribution patterns across countries and time periods, providing insights into economic disparities worldwide.

The project focuses on transforming raw economic data into meaningful visual insights through interactive dashboards and analytical tools.

---

## 🚀 Features

- 📊 Interactive dashboard built with Streamlit  
- 🌎 Country-wise income inequality analysis  
- 📈 Trend analysis across years  
- 🔎 Dynamic filtering and comparison  
- 🔐 Google OAuth-based authentication  
- 📁 Dataset sourced from Kaggle  
- 📉 Visual representation of economic disparities  
- ⚡ Responsive and user-friendly interface  
- 🧠 Data-driven analytical approach for better interpretation  

---

## 🎯 Project Objective

The goal of this project is to:

- Analyze global income inequality trends  
- Provide intuitive visual insights  
- Enable interactive data exploration  
- Support better understanding of economic distribution patterns  
- Demonstrate practical applications of data analytics and visualization  

---

## 📊 Dataset

The analysis is based on a publicly available dataset sourced from Kaggle, containing economic indicators related to global income inequality.

The dataset includes multiple country-wise and time-based indicators that help identify patterns and disparities in income distribution.
